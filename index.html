# HR 업무 보조 — 나의 Claude 설정

당신은 HR 전문가 보조 AI입니다.

- 교육 기획안: Kirkpatrick 4단계 구조
- 보고서: 요약 → 상세 → 액션 아이템
- 코드: 주석을 한국어로

- "~인 것 같습니다" (단정하지 않는 표현)
- "죄송합니다"로 시작하는 문장

선호 형식(Format) — 출력 양식
금지 표현(Banned) — 쓰면 안 되는 것

Hooks 설정 — 위험 명령 자동 차단 예시

.claude/settings.json 
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Bash",
      "hooks": [{
        "type": "command",
        "command": "cmd=$(jq -r '.tool_input.command'); if echo \"$cmd\" | grep -q 'rm -rf'; then echo '위험 명령어 차단됨'; exit 2; fi"
      }]
    }],
    "PostToolUse": [{
      "matcher": "Write",
      "hooks": [{
        "type": "command",
        "command": "echo \"[LOG] 파일 수정: $(date)\" >> ~/claude-log.txt"
      }]
    }]
  }
}
위 설정이 하는 일
🛡️ rm -rf 명령 감지 시 즉시 차단
📝 파일 수정 시마다 자동 로그 기록

matcher: "Bash" → bash 명령만 검사
matcher: "Write" → 파일 쓰기만 검사
matcher: "*" → 모든 도구 검사
matcher: "mcp__github__*" → GitHub MCP 전체 (v2.1.118+)
활용 아이디어
• Stop hook: 작업 완료 시 슬랙 알림 전송
• PreToolUse: prod DB 접근 전 확인 요청
• PostToolUse: git push 후 CI 상태 확인
• SubagentStop: 에이전트 결과 자동 저장
• mcp_tool (v2.1.118+): MCP 도구에 직접 Hook 적용
✨
mcp_tool 신패턴 (v2.1.118+)
기존: type: "command" → 셸 스크립트 경유
신규: type: "mcp_tool", server: "...", tool: "..." → MCP 직접 호출. 중간 스크립트 없이 더 안정적.
⚠️
주의
Hook 스크립트는 Claude와 같은 권한으로 실행됩니다. 신뢰할 수 없는 코드를 Hook에 넣지 마세요.

지금 당장 병렬화 가능한 업무

Subagents vs 단일 Claude 비교
단일 Claude: A완료 → B완료 → C완료 (직렬)
Subagents: A+B+C 동시 (병렬)

3개 작업 각 10분 → 단일: 30분 vs Subagents: ~12분

복잡할수록 효과 극대화

Subagents를 쓰면 시간이 더 걸리지 않나요?

CLAUDE.md에 민감한 정보를 넣어도 되나요?
절대 안 됩니다. 평문 파일이라 git에 올라가거나 다른 사람이 볼 수 있습니다. 민감 정보는 .env 환경변수로 관리하세요.
