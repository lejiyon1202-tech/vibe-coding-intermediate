# 리즈 Phase 0 — 직군별 케이스 골격 (S18~S22 대응)
> 작성: 리즈 | 2026-04-25 KST | Phase 0 산출물

---

## 케이스 1 — 개발자 (S18)

**시나리오**: PR 리뷰 요청이 쏟아질 때, 코드 품질 체크를 AI가 1차 자동화

**Before**:
- PR 올라오면 팀원이 하나씩 열어서 직접 읽음 → 리뷰 댓글 작성 평균 30~60분
- 급하면 형식적 리뷰 → 버그 나중에 발견 → 재작업

**After**:
- PR push 시 Hooks 자동 발동 → AI 1차 리뷰 (네이밍·에러 핸들링·중복 로직 감지) → 사람은 로직 판단만
- CLAUDE.md에 코드 스타일 가이드·금지 패턴 고정 → 프로젝트마다 재설명 불필요

**임팩트**:
- 리뷰 응답 시간 60% 단축 (30~60분 → 10~15분)
- 반복 지적 사항 0건 (CLAUDE.md 규칙으로 사전 차단)

**기술 파트 (카리나 작성 예정)**: Hooks(PreToolUse) + CLAUDE.md 코드 스타일 섹션

---

## 케이스 2 — 기획자 (S19)

**시나리오**: 회의 후 기획서 초안 작성에 반나절 쏟는 반복 업무를 AI로 단축

**Before**:
- 회의 종료 → 메모 정리 → 기획서 양식 열기 → 목적·배경·요구사항 직접 타이핑 → 2~3시간
- 초안 쓰다가 방향이 맞는지 의심 → 재검토 반복

**After**:
- Skills에 "기획서 초안 생성기" 등록 → `/기획서 [회의 핵심 3줄]` 입력 → 표준 양식 초안 30초 완성
- CLAUDE.md에 회사 기획서 포맷·금지 표현·필수 섹션 고정

**임팩트**:
- 초안 작성 시간 2~3시간 → 30분 이내
- 포맷 통일률 100% (팀 전체 동일 기획서 양식 사용)

**기술 파트 (카리나 작성 예정)**: Skills 커스텀 명령어 + CLAUDE.md 기획서 포맷 섹션

---

## 케이스 3 — HR/HRD 담당자 (S20)

**시나리오**: 교육 기획안 작성 + 강사 섭외 메일 + 수강 후기 분석을 각각 AI에 위임

**Before**:
- 과정 기획 → 목표·대상·커리큘럼 직접 작성 (3~4시간)
- 수강 후기 100건 → 엑셀로 직접 정리 → 인사이트 도출 (반나절)

**After**:
- Projects에 "HRD 과정 설계" 프로젝트 생성 → CLAUDE.md에 교육 프레임워크(Kirkpatrick 4단계·Bloom 분류) 고정
- `/수강후기분석 [파일첨부]` Skills 명령어 → AI가 긍/부정 분류 + 개선 포인트 자동 추출

**임팩트**:
- 과정 기획 초안 3~4시간 → 1시간 이내
- 수강 후기 분석 반나절 → 10분

**기술 파트 (카리나 작성 예정)**: Projects + CLAUDE.md 교육 프레임워크 섹션 + Skills 분석 명령어

## 케이스 4 — 리더·팀장 (S21)

**시나리오**: 주간 회의록 정리 + 팀원 성과 보고서 초안을 AI가 처리

**Before**:
- 주간 회의 60분 → 회의록 정리 30분 → 액션 아이템 추출 + 담당자 배분 → 총 90분
- 월말 성과 보고서: 팀원 4~5명 업무 취합 → 요약 → 경영진 보고용 변환 → 2~3시간

**After**:
- Subagents: "회의록 정리 에이전트" + "성과 요약 에이전트" 병렬 운용
- 회의록 붙여넣기 → 자동으로 액션 아이템·담당자·기한 추출
- 팀원 업무 일지 모아서 → 보고서 초안 자동 생성

**임팩트**:
- 회의 후 정리 90분 → 15분
- 월말 보고서 2~3시간 → 30분

**기술 파트 (카리나 작성 예정)**: Subagents 다중 에이전트 + CLAUDE.md 보고서 포맷·직급별 어조 고정

## 케이스 5 — 영업·CS 담당자 (S22)

**시나리오**: 고객사 제안서 초안 + 이메일 답변 초안을 AI로 반자동화

**Before**:
- RFP 수신 → 기존 제안서 뒤지기 → 맞춤화 작업 → 반나절~하루
- 고객 문의 메일 하루 20~30건 → 유사 내용 반복 답변 → 2~3시간

**After**:
- MCP(구글 드라이브) 연결 → 기존 제안서 자동 참조 + 맞춤화 초안 생성
- Skills에 "고객 답변 초안" 등록 → 문의 유형별 템플릿 자동 선택 + 커스터마이징

**임팩트**:
- 제안서 초안 하루 → 2시간
- 반복 메일 답변 2~3시간 → 30분

**기술 파트 (카리나 작성 예정)**: MCP(Google Drive) + Skills 답변 템플릿 + CLAUDE.md 고객사별 톤 설정
